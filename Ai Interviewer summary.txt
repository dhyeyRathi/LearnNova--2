# AI Interviewer — Component Summary & Walkthrough

## Overview
The AI Interviewer is an interactive, browser-based practice tool that simulates a live interview with "Nova", an AI interviewer. It guides users through role-specific or resume-based questions, records their text or voice responses, evaluates those answers, and provides detailed feedback and scoring.

## Interview Flow & Stages
1. **Rules Stage**: Introduction to the interview process, informing users about the camera, microphone functionality, and overall rules.
2. **Field Selection**: Allows users to choose an industry field (e.g., Software Engineering, Data Science, Product Management) and specific sub-fields if they do not provide a resume.
3. **Resume Upload (Optional)**: Users can upload a PDF resume for a customized interview. The AI parses the resume to extract skills and contextualize technical questions.
4. **Greeting Stage**: Nova introduces the interview process and rounds before starting the first timer.
5. **Interviewing Stage**: Proceeding seamlessly through 4 structured rounds. Managerial and HR rounds feature a dedicated "Think Timer" (20s) and "Answer Timer" (60s). Aptitude and Technical rounds have a 60s Answer Timer.
6. **Results Stage**: Synthesizes scores and provides comprehensive Gemini-generated feedback.

## Rounds — Detailed Breakdown
The interview is strictly organized into 4 distinct rounds. Each round consists of 3 questions.

### 1. Aptitude Round 🧠
- **Purpose**: Evaluates logical reasoning and general aptitude.
- **Topics**: Problem-solving logic, basic mathematics, and pattern recognition.
- **Timing**: 60 seconds to answer per question.

### 2. Technical Round 💻
- **Purpose**: Focuses on skills-based technical questions.
- **Dynamic Content**: Uses extracted skills from the user's resume or the predefined skills from the selected sub-field.
- **Timing**: 60 seconds to answer per question.

### 3. Managerial Round 👔
- **Purpose**: Assesses leadership, conflict resolution, and pressure handling.
- **Timing**: 20 seconds "Think Timer" to plan the response, followed by a 60-second "Answer Timer".

### 4. HR Round 🤝
- **Purpose**: Examines culture fit, motivations, and behavioral scenarios.
- **Timing**: 20 seconds "Think Timer" to plan the response, followed by a 60-second "Answer Timer".

## Tools and Services Used by the AI
The AI Interviewer leverages multiple internal and external tools to provide real-time, dynamic interview capabilities:

1. **Google Generative AI (Gemini 3.1 Flash Lite Preview)**
   - **PDF Extraction (Multimodal API)**: Reads base64-encoded PDF resumes to extract accurate, unformatted text.
   - **Resume Evaluation**: Analyzes the extracted text to provide a resume score, skills list, experience summary, and document feedback.
   - **Question Generation**: Generates tailored, non-repetitive questions for all four rounds based on user skills, field, and previous session data.
   - **Answer Evaluation**: Evaluates individual user answers during the interview. (Note: A local fallback script scores the answer based on word count, numbers, examples, and structure if Gemini fails).
   - **Comprehensive Final Feedback**: Generates end-of-session feedback utilizing the user's answers across rounds and their resume details.

2. **Web Speech API**
   - **Text-to-Speech (TTS) / SpeechSynthesis**: Allows Nova to speak instructions, questions, and feedback audibly using browser-native capabilities.
   - **Speech-to-Text (STT) / SpeechRecognition**: Transcribes the user's spoken answers directly into text form, avoiding external API latency.

3. **Supabase Database (Interview History Service)**
   - **Question Anti-Repetition Logic**: Before generating new questions, the AI securely retrieves all previously asked questions from the Supabase database. These questions are passed to the Gemini prompt so the user never gets the same question twice across different sessions.

## API Calls Breakdown (Gemini Model: `gemini-3.1-flash-lite-preview`)
The interview system is deliberately structured to minimize latency and token usage. A full practice interview session only requires 2 to 3 generative API calls:
1. **Resume Parsing (1 API Call — Optional)**: If a resume is uploaded, `analyzeResumeFromPDF()` uses Gemini's multimodal capabilities to extract and evaluate the PDF content in a single shot. 
2. **Question Generation (1 API Call)**: To avoid inter-round load times, `generateAllInterviewQuestions()` generates all 12 questions (for all 4 rounds) concurrently based on skills, field, and question history.
3. **Answer Evaluation (0 API Calls)**: User responses are not scored individually via Gemini during the flow. The system achieves 0 latency by relying on a local JS fallback (`scoreAnswerLocally()`) to review word counts, phrasing, structure, and inclusion of examples.
4. **Final Feedback (1 API Call)**: At the end of the interview, `generateFinalFeedback()` consumes all user responses across the 4 rounds to return a comprehensive analytical scorecard.

**Total Architecture Cost**: 2 API Calls (Without Resume) / 3 API Calls (With Resume)

## Scoring and Feedback
- **Resume Score**: A score (0-100) specifically assessing the clarity and completeness of the uploaded PDF resume.
- **Answer Scoring**: Each answer is scored initially out of 100 based on structure, depth, inclusion of examples, metrics/numbers used, and grammatical accuracy.
- **Round Metrics**: Question scores are compiled iteratively and factor into the global interview average score.
- **Final Card**: Detailed textual and calculated feedback, categorizing strengths and specific areas for improvement (such as adhering more closely to the STAR method).
